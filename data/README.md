# data/

Local data files for FoodMaps.

`data/raw/` is git-ignored: it holds the files you import into the database (`places.csv`, the 43 places
curated by the team, and `reviews.csv`, the export of the team's review form). Never commit them. How
to import and refresh the data: [../docs/DATA_IMPORT.md](../docs/DATA_IMPORT.md).

Every data comes from the team's own curation and from our own reviews.
